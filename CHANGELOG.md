# Changelog

All notable changes to PHPlastic will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [v0.6.1] - 2026-02-28
### Added
- **Full Internationalization:** Entire framework (UI, Controllers, Docs) translated to English.
- **Security Hardening:** Conducted full scan for hardcoded API keys; updated `.gitignore` for better protection.
- **Repository Cleanup:** Removed development artifacts and test modules (`Todo`, `Note`) for a production-ready state.
- **GitHub SEO Optimization:** English-first documentation and metadata for better discoverability.

## [v0.6.0] - 2026-02-26
### Added
- **AI SQL Migrations:** Automatic parsing and execution of DDL queries generated by Groq.
- **Dynamic Module Routing:** Route auto-discovery in `app/Modules/` for easier plugin development.
- **REST API Support:** Added `jsonResponse` helper and enhanced wizard prompts for API generation.

## [v0.5.0] - 2026-02-26
### Added
- **Visual Branding:** Developed "PHPlastic" logo and Hero Banner with Nano Banana.
- **Public Home Page:** Separate controller and views for showcasing websites/e-commerce.
- **AI Wizard Versatility:** Updated system prompts for non-administrative app component generation.
- **In-App Changelog:** Native Markdown-to-HTML parsing for viewing release notes in the dashboard.
- Centralized software versioning in core config.
- Global `Router@setNotFoundHandler` for elegant 404 errors.

## [v0.4.0] - 2026-02-26
### Added
- **Groq AI Driver:** Ultra-fast Scaffolding inference.
- **AI Patcher System:** Introduced `PolicyGate` (file protection) and `PatchManager` (Direct I/O writing).
- AI Cost & Token tracking system scaled for the new driver.
- "Apply Patch" button in Wizard.
- Dynamic LLM model selection in Settings.
- **Factory Reset:** Instant DB drop/rollback/migrate trigger in Settings zone.

## [v0.2.0] - 2026-02-25
### Added
- **RBAC System:** Role management (Admin, Manager, Operator, Viewer) and `Gate::allows` permissions.
- **Audit System:** Immutable user action tracking via `AuditLogger`.
- **Global Settings:** Database-stored runtime configuration.
- Tailwind views for Users, Audit Log, and Settings administration.

## [v0.1.0] - 2026-02-25
### Added
- Minimalist MVC project structure (PHP 8.2+).
- `Core\Router` with regex and Middleware support.
- `Core\View` pattern with anti-XSS `e()` helper.
- `Core\Config` loader (.env and PHP array support).
- `Core\Security` (CSRF, Secure sessions).
- Singleton PDO connection for SQLite (`app.sqlite`).
- **Auth Module:** Argon2id hashing, basic Rate Limiting, and inactivity logout.
- Admin Skeleton UI with Tailwind CSS.
- CLI Tooling (`tools/cli.php`) for migrations and admin creation.
